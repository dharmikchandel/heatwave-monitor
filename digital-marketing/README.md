# Digital Marketing — Experiment No. 08: AI-Based Customer Persona Generation

Course: Digital Marketing (KJSSE / IT / LYBTech / Sem-VII / 2026-27)

Segments the audience of **Heatwave Monitor** (the Next.js app in the parent folder) into customer personas with **k-means clustering** in Python, and suggests a digital marketing strategy for each persona.

> **The data is synthetic.** Heatwave Monitor is a free, keyless web app with no real customer database, so `data/customers.csv` is generated by `scripts/generate_dataset.py` (fixed seed 42). It simulates five plausible audience groups and deliberately contains duplicates, missing values and inconsistent labels for the cleaning step.

## Run it (uses `uv` only, no pip)

```bash
cd digital-marketing
uv sync                                    # create .venv and install dependencies
uv run python scripts/generate_dataset.py  # (re)generate data/customers.csv
uv run jupyter lab                         # open notebooks/expt_08_persona_generation.ipynb

# or execute the whole notebook headlessly, saving outputs into it
uv run jupyter nbconvert --to notebook --execute --inplace notebooks/expt_08_persona_generation.ipynb
```

## Layout

```
data/customers.csv                          synthetic marketing dataset
scripts/generate_dataset.py                 reproducible dataset generator
notebooks/expt_08_persona_generation.ipynb  the experiment (steps 1-10)
outputs/figures/                            PNG snapshots of every plot
outputs/personas.csv                        persona / cluster profile table
outputs/report.md                           lab write-up (aim, results, questions, outcomes, conclusion)
```
